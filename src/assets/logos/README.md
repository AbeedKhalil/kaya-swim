# Logos — drop-in slots

Save a logo here under one of these names and it appears automatically.
SVG is best (sharp at every size); `.png` or `.webp` also work (at least 640 px wide, transparent background).

| File name (any extension) | Where it appears                                                   |
| ------------------------- | ------------------------------------------------------------------ |
| `logo-main`               | Header, mobile menu, and the hero's "Adults" board                 |
| `logo-kids`               | Hero, "Kids & teens" board                                         |
| `logo-adults` (optional)  | Hero, "Adults" board — only if it should differ from `logo-main`   |

Current files: `logo-main.png` (the swimmer / "מרכז מצויינות לשחייה" logo) and `logo-kids.png`
(the turtle / "חווית המים" logo), trimmed and resized from the originals.

The hero boards and the header are light, so dark or colourful logos work there. Replacing a logo:
save the new file under the same name (delete the old one if the extension changes).
